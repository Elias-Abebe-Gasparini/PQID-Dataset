# PQID Public Release Plan

Last updated: 2026-05-23

## Release Stance

PQID is construction-complete and freeze-ready as a research artifact, but the
public release must be license-filtered. The canonical full instruction splits
remain internal construction artifacts unless a row is in a license-resolved
release view.

Immediate rule:

- release the default hosted dataset as the strict permissive-only
  `public_open` view
- document the broader `license_valid` view for auditability, including
  copyleft and manually reviewed `other` rows with downstream obligations
  preserved
- exclude `no_license` rows from public training payloads
- keep unresolved/no-license material restricted unless upstream license
  evidence is later supplied

## v1.0.1 License-Evidence Refresh

The v1.0.1 refresh reclassifies `49,044` historical `wjy99-c/QDiff` rows as
BSD-3-Clause based on the current `UCLA-SEAL/QDiff` root license and matched
file-path/blob evidence. It also normalizes the former missing-license-category
tail into explicit `no_license`, leaving `0` rows in the internal missing
license-category manifest.

## Dataset Card Requirements

The public dataset card should state:

- the uploaded files are a license-filtered release view, not the full internal
  construction corpus
- row-level license metadata is retained
- the default hosted payload is the permissive-only `public_open` view
- copyleft and manually reviewed `other` rows are documented in the
  `license_valid` summaries but are not part of the default hosted payload
- unresolved/no-license rows are excluded pending provenance or permission
  resolution
- the full construction-complete dataset is described in the papers, but not all
  rows are publicly redistributed
